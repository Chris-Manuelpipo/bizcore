# BizCore — Portail développeur

## Register

product

## Product Purpose

Portail web où les développeurs s'inscrivent, provisionnent des tenants et génèrent des clés API (`bcs_live_…`) pour intégrer l'API métier BizCore via `X-Api-Key`.

## Users

Développeurs backend ou full-stack intégrant BizCore dans leurs applications. Sessions courtes, alternance IDE / navigateur, besoin de clarté sur secrets one-time et usage des clés.

## Tone

Précis, sobre, orienté tâche. Pas de marketing dans le portail.

## Anti-references

Hero metrics SaaS, grilles de cartes identiques, glassmorphism décoratif, gradient text, modales systématiques, confirm() natif.

## Strategic principles

1. Flux tenant → clé → intégration, jamais l'inverse.
2. Secret API affiché une seule fois, copie explicite.
3. Cohérence sombre/clair pour bureau jour et soirée.
